# Agent instructions

## Supported platform scope

Per the platform-scope decision in [#1550](https://github.com/danieljustus/symaira-vault/issues/1550), product targets are Apple (macOS arm64 and iOS) and Web. Native Windows and macOS Intel are no longer required (platform scope decision 2026-10-29, #1550). Linux remains supported as a CI/server platform and CLI target. Do not treat historical Windows or macOS Intel parity requirements in older documents as current acceptance criteria.
