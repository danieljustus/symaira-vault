and diffing the command trees (depth 3). Commands and flags only — it does not
claim behavioural parity for the commands that do exist. Regenerate with the
same walk whenever the surface changes; the raw JSON lives in
`target/resume-evidence/cli-gap-inventory.json` after a run.
